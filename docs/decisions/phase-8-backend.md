  CORRECTED note, bulk reason): JavaScript's `trim()` removes U+FEFF but not U+200B, U+2060, the Hangul

  refusals a minute with one account can set `RATE_LIMIT_ATTENDANCE_REFUSALS_PER_MINUTE` higher.
